# Day 1 — Programming Foundations

## 1. Learning goals

- Understand programming.
- Understand algorithms.

## 2. Concepts taught

### Programming

Programming means giving a computer instructions to perform tasks.

### Algorithm

An algorithm is a sequence of steps used to solve a problem.

### Input

Information given to a program.

### Processing

Work performed on the input, such as calculations.

### Output

The result displayed by the program.

### Variables

A variable is a named place used to store a value.

## 3. First algorithm — Shop bill

Items:
- 3 pens at Rs. 10 each.
- 2 books at Rs. 25 each.
- 4 pencils at Rs. 5 each.

Algorithm:
1. Input pen quantity and price.
2. Multiply quantity by price.
3. Input book quantity and price.
4. Multiply quantity by price.
5. Input pencil quantity and price.
6. Multiply quantity by price.
7. Add all item totals.
8. Display final bill.

Calculation:
- Pens = 3 * 10 = Rs. 30
- Books = 2 * 25 = Rs. 50
- Pencils = 4 * 5 = Rs. 20
- Final total = Rs. 100

## 4. Second exercise — Apples and oranges

- 5 apples at Rs. 8 = Rs. 40
- 3 oranges at Rs. 10 = Rs. 30
- Final bill = Rs. 70

Result: All 3 answers correct.

## 5. Third exercise — Bags, bottles and boxes

User's algorithm:

Start
Input bq, bp, oq, op, xq, xp
bt = bq * bp
ot = oq * op
xt = xq * xp
total = bt + ot + xt
Display total
Stop

Meanings:
- bq = bag quantity
- bp = bag price
- oq = bottle quantity
- op = bottle price
- xq = box quantity
- xp = box price
- bt = bag total
- ot = bottle total
- xt = box total

Example calculation:
- Bags = 2 * 150 = Rs. 300
- Bottles = 3 * 20 = Rs. 60
- Boxes = 1 * 80 = Rs. 80
- Final total = Rs. 440

Result: Algorithm correct.
