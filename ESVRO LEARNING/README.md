# ESVRO LEARNING

My personal programming classroom.

## Learning goals

- Learn programming from beginner level.
- Learn algorithms and problem-solving.
- Master Dart.
- Learn Flutter.
- Understand databases and SQL.
- Learn accounting fundamentals.
- Learn testing, debugging and software architecture.
- Build ESVRO independently.

## Teaching method

- ELI5 explanations.
- Logic before syntax.
- Every line of code explained.
- Exercises before complete solutions.
- Daily learning records.
- Practical projects.

## Rule

I will write and understand my own code.
AI is my teacher and assistant, not a replacement for learning.
